Theme documentation

Tarifa

A Shopify theme for catalogues bought in quantities · v0.25.0

Tarifa is a Shopify theme for catalogues that are bought in quantities: wholesale price lists, spare parts, consumables and training seats. This guide covers installation, the three presets, the metafields the theme reads and the quantity discounts.

1. Install

  1. In your Shopify admin go to Online Store → Themes.
  2. Click Add theme → Upload zip file and choose the theme package.
  3. Click Customize to open the theme editor, or Publish when you are ready.

The theme works without any app. You do not need to install anything else to use the price breaks, the quick order page or the seven languages.

2. Before you start: what the theme expects

Tarifa reads two product metafields. Both are optional: without them the theme falls back to the defaults set in the section.

Metafield Type What it is for
custom.tramos JSON Price breaks for that product
custom.ficha JSON Technical specifications for that product

custom.tramos

[
  { "q": 10,  "d": 5  },
  { "q": 25,  "d": 10 },
  { "q": 100, "d": 18 }
]

q is the minimum quantity, d is the percentage off. Create it in Settings → Custom data → Products → Add definition, namespace custom, key tramos, type JSON.

If a product has no tramos, the theme uses the three breaks configured in the product section settings.

custom.ficha

[
  { "k": "Format",     "v": "30 ml" },
  { "k": "Skin type",  "v": "All" },
  { "k": "Made in",    "v": "Spain" }
]

Namespace custom, key ficha, type JSON. It renders as the specification table on the product page.

3. Presets

The theme ships with three presets. Switch between them in the theme editor, under Theme settings → Presets. Each preset has its own colours, its own homepage and its own demo store.

Preset Look For
Tarifa Editorial, warm, generous imagery Brands that sell to the public and to the trade
Trade Dense, reference-first, counter-facing Catalogues that only speak to professionals
Industrial Dark graphite, orange accent, technical Spare parts, MRO, industrial supply

Presets change presentation only. Your products, pages and content stay where they are.

4. Theme settings

Theme settings → Colors exposes 17 colours: ink, body text, three muted greys, accent, strong accent, brand, soft background, two borders, alternate background, surface, button background, button text, overlay panel, text on ink, and the logo treatment.

Changing a colour here changes it everywhere: sections, cards, forms, header and footer all read the same variables.

Theme settings → Typography sets the body font. Layout sets the page width and margins.

The logo is text by default (Be Shana style). If you upload an image logo instead, the Logo treatment setting can invert it for dark presets.

5. Sections

Every page is built from sections you can reorder, remove and duplicate:

  • Slideshow
  • Featured collection
  • Image with text (banner)
  • Testimonials
  • Benefits row
  • Newsletter
  • Page content
  • Contact form
  • Quick order

The Quick order section puts the catalogue in a table: pick a product or type a reference, set the quantity, see the line price with its break applied, and send the whole order to the cart.

6. Price breaks: what the theme does and what it does not

Tarifa shows the break table, calculates the line total and updates it as the quantity changes. It does not apply the discount itself. The discount is applied by Shopify (or by an app) at the cart and checkout.

To make the discount real, create automatic quantity discounts in Discounts → Create discount → Amount off products → Automatic discount, one per break, with Minimum quantity of items set to the same number as the metafield:

Break Discount Condition
10+ 5 % Minimum quantity of items: 10
25+ 10 % Minimum quantity of items: 25
100+ 18 % Minimum quantity of items: 100

Keep the two in sync. If the metafield says 10 % and the Shopify discount says 12 %, the customer sees one price on the product page and another at checkout.

If you are on Shopify Plus, the native alternative is B2B catalogues with volume pricing, which sets the price per break per variant instead of stacking automatic discounts.

7. Languages

Seven interface languages: English, Spanish, French, Italian, German, Portuguese and Dutch. Add them in Settings → Languages. Right-to-left languages (Arabic, Hebrew, Persian, Urdu) switch the layout direction automatically.

8. Accessibility

Skip link to the content, visible focus, labelled forms, keyboard-operable carousel and menus, and a slideshow that respects prefers-reduced-motion.

9. Frequently asked questions

Do I need an app? No. Filters, search, quick view, cart drawer, quick order and languages are part of the theme.

Why does the cart show a different price than the product page? Because the discount is applied by Shopify at the cart and the break table is informational. Check that the automatic discount and the metafield use the same numbers.

Can I use only the wholesale preset? Yes. Presets share the same code; the content does not change when you switch.

Where do I change the colours? Theme settings → Colors. All sections read the same variables.

How do I add a new break? Edit the product metafield or change the three default breaks in the product section settings.
